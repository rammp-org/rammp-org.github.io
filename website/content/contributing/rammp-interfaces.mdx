# RAMMP-interfaces spec

`RAMMP-interfaces` is the shared vocabulary of the system: the message, service
and action types that every module uses to talk to every other module. It is
compiled into [`rammp-base`](/contributing/how-to#select-rammp-base-image), so any
module built on a RAMMP base image already has it.
