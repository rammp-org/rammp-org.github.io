### Declare what it speaks

The fragment is how the rest of the system finds out what your module publishes
and subscribes to. Use the message types in
[`rammp-ros2-interfaces`](/interfaces) — do not invent a new type when one
already fits.

```yaml
# TODO: a real fragment for a small module
name: <your-module>
publishes:
  - topic: /your/topic
    type: <package>/msg/<Type>
subscribes:
  - topic: /some/input
    type: <package>/msg/<Type>
```

<Callout type="warning">
  _[The rule people get wrong: every topic the code actually touches has to
  appear here, including the ones you only read.]_
</Callout>

### Build and check it locally

The template's make targets are the same everywhere — see
[Build a module](/building).

```bash
make build   # image builds
make check   # lint, types, unit tests
make smoke   # container comes up and speaks
```

> **Fill in** — _[what the smoke test starts, what it asserts, and how long it
