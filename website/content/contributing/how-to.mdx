## Docker

Every node in the RAMMP system runs as a Docker container, which allows each node to run their own dependencies and environment variables independently of all other containers. Installation instructions are here: _[https://docs.docker.com/engine/install/ubuntu/]_

### Build and test locally

you are — see [Build a module](/building).

```bash
make build   # build the image
make check   # lint, types, unit tests
make smoke   # bring the container up and confirm it speaks
```

### How to publish

Publishing makes your image pullable by everyone else, and by the machine that
actually runs the chair.

<Steps>

#### Let CI build and push it

> **Fill in** — _[what the template's workflow does, what triggers it (push to
> main, a tag, a release), and where the image lands.]_

```bash
# The image CI produces
ghcr.io/rammp-org/<your-repo>:<tag>
```

#### Or push once by hand

```bash
docker build -t ghcr.io/rammp-org/<your-repo>:<tag> .
docker push ghcr.io/rammp-org/<your-repo>:<tag>
```
