# Software versions & core repos

The versions every module is built against, and the repositories you clone to
stand up the robot and a development environment. Modules built on top of
this stack are listed in the [Modules registry](/modules).

## Versions

| | Version | Notes |
| --- | --- | --- |
| JetPack | 6.2.3 | The base images accept 6.1 or newer. Not 6.0: its L4T r36.2 and r36.3 driver predates the CUDA 12.6 runtime in `rammp-cuda`. |
| Jetson Linux (L4T) | r36.5.2 | Check with `head -1 /etc/nv_tegra_release`. |
| OS | Ubuntu 22.04.5, arm64 | On the host and inside every image. There is no amd64 build of anything. |
| Kernel | Linux 5.15, PREEMPT_RT | `5.15-rt-tegra`, for the arm's 1 kHz loop. Why the chair needs it is on the [hardware page](/platform#real-time). How to install it is in [Developer setup](/setup#the-jetson). |
| CUDA | 12.6.11 | The driver comes from the host's L4T. The runtime libraries ship inside `rammp-cuda`. |
| Docker Engine | 27.5.1 | With the `nvidia` runtime that JetPack installs. |
| ROS 2 | Humble | |
| RMW | Cyclone DDS | Selected, not just installed, in the base images. The interface versioning rules assume it. |
| Python | 3.10.12 | On the host and inside the images. |
| `rammp-base`, `rammp-cuda` | 1.0.0-jp6 | The base images every module builds `FROM`. See [Base images](/publishing/base-images). |
| `rammp-interfaces-ros2` | v1.0.0 | Compiled into the base images at this tag. See [the spec](/interfaces/rammp-interfaces-ros2). |
| sheppy | installed from `main` | One-line install in [sheppy → Getting started](/sheppy/getting-started#install). Pin a ref with `SHEPPY_REF`. |

The base image tag `<semver>-jp<N>` carries two of these: the semver tracks
the interface contract, and `jp6` names the JetPack generation. Bumping either
means rebuilding every module against the new tag.

## Core repositories

Clone these to run the robot and to develop against it. Each is a separate
repository under [rammp-org](https://github.com/rammp-org).

| Repository | What it is | Who depends on it |
| --- | --- | --- |
| [rammp-deployments](https://github.com/rammp-org/rammp-deployments) | The sheppy manifest for each robot deployment. One directory per deployment, such as `december_2026/`. Says which modules run on the chair and how. | Anyone bringing the chair up. Every module, once it is deployed. |
| [RAMMP-docker](https://github.com/rammp-org/RAMMP-docker) | The `rammp-base` and `rammp-cuda` base images, the module Dockerfile template, and the smoke test. | Every module image. |
| [rammp-interfaces-ros2](https://github.com/rammp-org/rammp-interfaces-ros2) | The shared ROS 2 message, service and action definitions. Two packages: `rammp_common_interfaces` and `rammp_arm_interfaces`. | Every module, through the base image. |
| [sheppy](https://github.com/rammp-org/sheppy) | Launches and supervises every module on the chair from one manifest. Documented under [sheppy](/sheppy). | Anyone running the system. |
| [kinova-gen3-driver](https://github.com/rammp-org/kinova-gen3-driver) | The C++ low-level driver for the Kinova Gen3 arm. Owns the 1 kHz real-time control loop. | `kinova-gen3-ros2`. |
| [kinova-gen3-ros2](https://github.com/rammp-org/kinova-gen3-ros2) | The ROS 2 front end to the arm driver. Documented under [Controlling the arm](/kinova-gen3-ros2). | Anything that moves the arm. |
| [rammp-suite-software](https://github.com/rammp-org/rammp-suite-software) | Driver containers for the chair's cameras: the Orbbec Gemini 336L scene camera and the Intel RealSense D405 wrist camera. | Perception modules. The deployment manifest. |
