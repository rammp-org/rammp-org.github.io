# RAMMP

This site is the developer documentation for RAMMP.

RAMMP, the Robotic Assistive Mobility and Manipulation Platform, is an
ARPA-H funded program led by the [Human Engineering Research Laboratories
(HERL)](https://www.herl.pitt.edu/) at the University of Pittsburgh. It
develops robotic assistive technology that helps people with mobility
impairments live more independently. The program itself is described at
[rammp.tech](https://rammp.tech/).
