# RAMMP

This site is the developer documentation for RAMMP. It covers what you need to
get started building on the platform: the hardware you are building against,
the interfaces the modules use to talk to each other, and how to write, publish
and deploy a module of your own.

RAMMP, the Robotic Assistive Mobility and Manipulation Platform, is an
ARPA-H funded program led by the [Human Engineering Research Laboratories
(HERL)](https://www.herl.pitt.edu/) at the University of Pittsburgh, developing
robotic assistive technology that helps people with mobility impairments live
more independently. To learn more about the program itself, see [rammp.tech](https://rammp.tech/).
